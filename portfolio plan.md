### **3.1 Robot Directives**

We must explicitly tell search engines they are allowed to index the site.

**Action:** Create a file named robots.txt in the public/ directory of the Next.js project.

**File Content:**

Plaintext

\# Allow all crawlers  
User-agent: \*  
Allow: /

\# Disallow admin or private routes if any exist  
Disallow: /api/private/

\# Sitemaps  
Sitemap: https://www.rajadubey.in/sitemap.xml

### **3.2 XML Sitemap**

**Action:** Install next-sitemap to auto-generate a sitemap during the build process. This ensures every new project page is automatically indexed.

**PAGE 7: PHASE 5 \- PERFORMANCE (CORE WEB VITALS)**

The **Interaction to Next Paint (INP)** is **0.893s**34, which is nearly 4x slower than Google's recommendation (0.2s).

### **7.1 Hydration Optimization**

The delay is likely caused by heavy JavaScript loading on the main thread during the initial render.

**Strategy:**

1. **Lazy Load Icons:** The Lucide-React icons can be heavy if the whole library is imported. Ensure tree-shaking is active.  
2. **Defer Animations:** If using Framer Motion, avoid animating the entire layout tree at once.  
   * *Change:* \<motion.div animate={{...}}\>  
   * *To:* \<motion.div whileInView={{...}} viewport={{ once: true }}\> (This delays animation until the element is actually visible).

### **7.2 Script Loading**

If analytics or third-party widgets are used, they must not block the main thread.

Implementation:  
Use the Next.js Script component with the lazyOnload strategy.

JavaScript

import Script from 'next/script'

\<Script   
  src="https://third-party-analytics.com/script.js"   
  strategy="lazyOnload"   
/\>
